# Politica de Privacidad - Game Over (bot de Discord)

Ultima actualizacion: 10 de octubre de 2026

Esta politica explica que datos trata el bot de Discord de Game Over App.

## 1. Datos que se tratan

El bot lee los mensajes del canal de texto configurado unicamente para detectar sus comandos (por ejemplo !audio bocina). Para funcionar puede ver el identificador del servidor, del canal y del usuario que escribe el comando, y sus roles, solo para comprobar si esta autorizado y aplicar el tiempo de espera entre usos.

## 2. Datos que NO se guardan

El bot no almacena mensajes, no guarda historiales de conversacion, no registra contenido de voz ni escucha el audio del canal. Los identificadores se usan en memoria durante la sesion y no se guardan en ninguna base de datos.

## 3. Audios

Los audios que reproduce el bot proceden del canal de audios configurado o de archivos locales del propietario. Se guardan temporalmente en la cache del equipo donde se ejecuta el bot.

## 4. Comparticion de datos

No se venden, ceden ni comparten datos con terceros. El bot funciona sobre la plataforma de Discord, que trata los datos segun su propia politica: https://discord.com/privacy

## 5. Seguridad y conservacion

No se conservan datos personales mas alla de la sesion en la que se usa el bot.

## 6. Tus derechos

Puedes pedir en cualquier momento que se retire el bot de tu servidor expulsandolo, y dejar de usar sus comandos. Para cualquier duda sobre privacidad abre una incidencia en https://github.com/rulfux83-spec/game-over-discord/issues

Condiciones del Servicio: https://rulfux83-spec.github.io/game-over-discord/terminos.html
